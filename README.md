# TrainWithPapa 💪

A simple, mobile-friendly bilingual workout guide built for Papa.

TrainWithPapa removes the need to remember workout schedules, exercises, sets, reps, warm-ups, alternatives, and stretches. Papa can simply open the page and see exactly what he needs to train that day.

## Languages

- English
- ਪੰਜਾਬੀ (Punjabi / Gurmukhi)

The language can be changed with one large button and the choice is remembered on the device.

## Weekly Plan

| Day | Focus |
| --- | --- |
| Monday | Chest + Light Triceps |
| Tuesday | Back + Light Biceps |
| Wednesday | Recovery + Walking + Balance |
| Thursday | Legs |
| Friday | Shoulders + Light Core |
| Saturday | Arms + Walking |
| Sunday | Recovery + Stretching |

## Features

- Automatically opens today's workout
- English / Punjabi language toggle
- Beginner-friendly exercise selection
- Mostly 2 working sets per exercise
- Warm-up before each workout
- Sets and rep targets
- Rest-time guidance
- Simple step-by-step exercise instructions
- Alternative exercise for each main movement
- Post-workout stretching
- Walking, recovery and balance work
- Previous / next day navigation
- Large mobile-friendly controls
- Set-by-set checkboxes
- Last-performed date stored automatically for each exercise
- Animated in-card exercise demonstrations for matched movements
- Workout completion button
- Progress and language choice stored locally
- No account or database required

## Training Approach

The routine is intentionally conservative for a beginner. It emphasizes controlled repetitions, stable movements, manageable volume, recovery, walking, balance, and steady breathing rather than heavy lifting or training to failure.

## Safety

TrainWithPapa is a general fitness guide, not individualized medical advice. Exercise selection and training volume should be adjusted for age, experience, injuries, medical conditions, and clinician guidance where appropriate.

Never hold your breath while lifting. Stop exercising and seek appropriate medical attention for symptoms such as chest pain, fainting, severe dizziness, or unusual shortness of breath.

## Exercise Artwork

Exercise illustrations are provided by the open-source [Workout Guide](https://github.com/bryllim/workout-guide) project by Bryl Lim, based in part on artwork by Everkinetic.

The visual assets are licensed under **CC BY-SA 4.0**. TrainWithPapa loads the three published SVG frames for matched exercises and cycles them in the exercise card to create a lightweight demonstration animation.

Exercises without an exact reviewed visual match intentionally show a placeholder rather than an incorrect demonstration.
