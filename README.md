# PapaFit 💪

PapaFit is a simple workout companion I built for Papa to make going to the gym easier and more enjoyable.

Instead of remembering workout schedules, exercises, sets, and reps, he can simply open the webpage and see exactly what he needs to train that day.

The goal is to keep everything extremely simple, clear, and mobile-friendly — no accounts, complicated menus, or unnecessary features.

PapaFit provides:

- Today’s muscle group
- Daily warm-up routine
- Exercise-by-exercise guidance
- Sets and rep targets
- Alternative exercises
- Post-workout stretching
- Weekly workout schedule
- Simple progress/check-off controls

Built with HTML, CSS, and JavaScript and hosted using GitHub Pages.
