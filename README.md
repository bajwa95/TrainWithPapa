# TrainWithPapa 💪

A simple, mobile-friendly daily workout guide built for Papa.

TrainWithPapa removes the need to remember workout schedules, exercises, sets, reps, warm-ups, alternatives, and stretches. Papa can simply open the page and see exactly what he needs to train that day.

## Features

- Automatically opens today's workout
- One main training focus per day
- Beginner-friendly exercise selection
- Warm-up before each workout
- Sets and rep targets
- Alternative exercise for every main movement
- Rest-time guidance
- Post-workout stretching
- Previous / next day navigation
- Large, simple mobile interface
- Set-by-set checkboxes
- Workout completion button
- Progress stored locally in the browser — no account or database required
- Responsive design for phones, tablets, and desktops

## Weekly Plan

| Day | Focus |
| --- | --- |
| Monday | Chest |
| Tuesday | Back |
| Wednesday | Legs |
| Thursday | Shoulders |
| Friday | Arms |
| Saturday | Core + Mobility |
| Sunday | Recovery |

The routine is intentionally conservative for a beginner. It prioritizes controlled repetitions, machines, and stable movements rather than advanced or unnecessarily heavy lifts.

## Built With

- HTML
- CSS
- Vanilla JavaScript
- Browser localStorage
- GitHub Pages

## How It Works

The current day is detected automatically. Exercise checkboxes and workout completion are stored only on the device using `localStorage`, so Papa does not need to create an account or sign in.

## Safety

TrainWithPapa is a general fitness guide, not individualized medical advice. Exercise selection and training volume should be adjusted for age, experience, injuries, medical conditions, and clinician guidance where appropriate.

Stop exercising and seek appropriate medical attention for symptoms such as chest pain, fainting, severe dizziness, or unusual shortness of breath.
